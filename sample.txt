Artificial Intelligence (AI) is the simulation of human intelligence by machines.
Machine Learning is a subset of AI that enables systems to learn from data without being explicitly programmed.
Deep Learning is a subset of Machine Learning that uses neural networks with many layers.
Generative AI refers to models that can create new content such as text, images, or code.
A Large Language Model (LLM) is a type of AI model trained on massive text data to understand and generate human language.
Retrieval-Augmented Generation (RAG) combines a retrieval system with an LLM to answer questions using external documents.
